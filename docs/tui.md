# TUI 布局与配色

这张界面只有四段，从上到下：**标签行 / 对话 / 模态区 / 分隔线 + 输入 / 状态栏**。第一条会话就占用屏幕第一行：只有一条时是标题栏（`▤ 标题`），两条以上变成可切换的标签行——内容区滚动时它不动。历史滚过一屏后，对话区顶部那条「已进入会话：…」会跟着滚走，常驻标题只在这一行。顶部不再有常驻的版本或状态行；输入行紧贴状态栏，键位提示并进状态栏右侧——终端应用的惯例（vim、tmux）是最后一行永远是状态，输入就在它上面一行。

```
› 把 stats.Sum 的循环边界修掉
  ⚙ read_file stats/stats.go
  ↳ read_file 完成（12 ms）
jiaoag: 修好了：循环改回 i < len(nums)。

✎ 待审批 internal/llm/retry.go（+6 −2）
────────────────────────────────────────────
@@ -18,7 +18,11 @@
-old
+new
────────────────────────────────────────────
▸[y] 批准一次◂   [a] 本会话内都批准   [n] 拒绝
tab 切换焦点 · enter 执行 · esc 收起（不裁决）
────────────────────────────────────────────
● 已连接  ⌂ ~/code/api  ▤ 修登录超时  [等待审批]  tsk_7a408a1b  第 3 轮   agnes/agnes-3.0-flash  12.4k tok  ctx 5.2k/32k
```

面板打开时状态栏不再重复键位——面板自己的底栏已经写了按钮与按键。

## 状态栏

左边是「在哪、在干什么」，右边是「用什么模型、花了多少」：

| 段 | 含义 | 放不下时 |
|---|---|---|
| `● 已连接` / `● 未连接` | 与服务端的 WS 状态 | 永远保留 |
| `⌂ ~/code/api` | 会话工作区（`~` 缩写，过长砍中间保留仓库名） | 倒数第二个丢 |
| `▤ 修登录超时` | 会话标题（`/sessions` 里 `t` 或 `/rename` 改）；**没起名时整段不显示**——id 是给命令行和日志用的，不占状态栏 | 较晚丢（先于工作目录丢） |
| `[运行中]` 等 | 任务状态；有审批面板时固定显示「等待审批」 | 永远保留 |
| `tsk_…` | 运行中的任务 id | 先丢 |
| `第 N 轮` | agent 轮次 | 先丢 |
| `排队 N` | 队列深度 | 较晚丢 |
| `下一条 <model>` | 用 `/model` 绑定的单次模型 | 先丢 |
| `provider/model` | 本次实际使用的模型：会话指定过就用会话的，否则取 `assistant.start` 回报的（跟随服务端默认或 `/model` 单次覆盖） | 只在前者都放得下时显示 |
| `12.4k tok` | 本任务累计 token（prompt + completion） | 与上下文挤在一起时先丢它 |
| `ctx 5.2k/32k` | 这一轮请求的上下文占用 / 预算（`agent.context_budget_tokens`）。占用是本地估算值——供应商不回「还剩多少上下文」，估算器按字符类别加权并用每轮 `prompt_tokens` 校准 | 在 token 用量之后丢 |
| `enter 发送 · esc 取消 · ? 键位` | 当前可用键位（默认态才有） | 最先丢（整项放不下就省略） |

右侧按「模型 → 上下文 → 累计 token」排优先级：放不下时从尾部开始放弃，所以模型名最后才消失（不知道谁在答就没法判断回答该不该信）。窄屏（< 80 列）通常只剩模型与上下文两段。键位提示是第一个被牺牲的，按项整条省略而不是截成半句。连接状态、目录、任务状态三者永远在。

对话第一条是**入口表头**（`已进入会话：修登录超时` / `继续会话：…` / `切换到会话：…`）。它只在有标题时带标题，没标题写「（未命名，/rename 可命名）」——不摆会话 id。改名会就地改写这行（回帧与事件两条路径都改），所以第一行永远和状态栏的 `▤` 一致。

## 多会话标签

启动时本目录的会话会**全部开成标签**并接到最近更新的那条上（没有才新建）——每次启动都新建只会攒下一堆看不见的孤儿会话。想再开一条新的用 `/new`（同一个工作区、同样的附加根）。会话很多时标签行只显示当前那条附近，两端用 `…` 与 `+N` 标出还有多少。

其余操作：`/sessions` 面板里 `enter` 把已有的会话作为标签打开（**不会再因为它在跑任务而拒绝**），`ctrl+n` / `ctrl+p` 在标签之间循环，`ctrl+w` 关掉当前标签（至少留一个）。

```
1 修登录超时!  [2 ● 重构中间件]  3 ·4 压测脚本
（对话与工具调用……）
────────────────────────────────────────────
› 输入
● 已连接  ⌂ ~/code/api  ▤ 修登录超时  [等待审批]  ...
```

标签行在最上面而不是状态栏上方：它回答「这个窗口里开着哪几条会话」，属于导航；底部那一行留给「我在这条会话里干什么」。放顶部还有个实际好处——历史滚上去时标签始终可见，不会因为内容变多而离开视野。

标签只显示状态，不放正文：`[2 ● 重构中间件]` 里 `2` 是序号、`●` 表示那条会话正在跑任务、数字前的高亮表示它是当前标签。标记的优先级从高到低是：

| 标记 | 含义 |
|---|---|
| `!` | 有没裁决的审批——**最需要注意**，先切过去批掉 |
| `●` | 正在跑任务 |
| `◌` | 排队中 |
| `✖` | 上次任务失败 |
| `·N` | 有 N 条未读输出（`assistant.message` 或工具结果） |

后台会话的事件照常到达，但只更新标签上的徽标，不动当前对话区——否则两条会话的流会插在一起。切回去时从 `seq=0` 全量回放，对话、工具调用、审批面板都会重建，所以关掉标签再打开也不丢内容。

切换**不**退订其它会话（否则后台任务的徽标就停了），只有 `ctrl+w` 关标签才退订。正在跑的会话不会被切走时打断：任务在服务端跑，标签一直在，只是你不看。

## 自动应用的写入

`agent.write_approval: workspace`（默认）下，工作区与临时目录内的普通写入不再弹审批面板，
对话里只出现一行「自动应用（工作区内）：path」；敏感路径（`.git/`、`.env*`、密钥、
`AGENTS.md`、`.jiaoag/` 等）与工作区之外仍然弹 diff。免审写入同样有 `proposal.*` 事件与
`write.auto` 审计，事后可查；见 [`docs/write-approval.md`](write-approval.md)。

## 退出

`ctrl+c` 任何时候都能退（审批面板打开时也有效）。输入行里也可以敲 `/exit`（或 `/quit`）：它在会话检查之前处理，所以**没有会话、连接刚断**时同样能退——这两个场景恰恰是最想退出的时候。

## 样式

样式只在渲染时施加，`m.dialog` 里始终是纯文本——回放、测试、日志都不依赖转义序列。

| token | 颜色 | 用在哪 |
|---|---|---|
| accent | 青 | 提示符、选中、diff 块头、面板键位 |
| ok | 绿 | 完成、diff 增行、已连接 |
| warn | 黄 | 等待审批、排队、需要留意 |
| err | 红 | 失败、diff 删行、断线、拒绝按钮 |
| muted | 亮黑 | 元信息、耗时、路径、次要提示 |
| strong | 加粗 | 角色名、路径、当前项 |

`NO_COLOR`（任意值）或 `TERM=dumb` 关闭全部颜色，文本与布局不变；焦点用 `▸ … ◂` 包裹而不是只靠背景色，所以在无色终端里也能看出当前按钮。

## 审批按钮

三个按钮固定顺序：**批准一次 / 本会话内都批准 / 拒绝**。

- `tab` 前移、`shift+tab` 后退、`←→` 同效，`enter` 执行焦点所在的按钮。
- `y` / `a` / `n` 仍然直达，不必先移动焦点。
- 焦点落在「拒绝」时用红色描边（无色终端靠 `▸ ◂`），避免连按 tab 手滑。
- `esc` **不裁决**：只收起卡片让出屏幕，状态栏继续显示「等待审批」，再按 `esc` 展开。
- 逐块模式（`v`）下按钮换成「应用选中块 / 取消」。

## 全屏（默认）

TUI 默认占满整个窗口（alternate screen，和 vim/htop 一样）：状态栏与输入行钉在终端底行，内容超出视口后自己滚动。

滚动键：`pgup`/`pgdn` 一页、`ctrl+u`/`ctrl+d` 半页、`home` 跳到最早、`end` 回到最新。翻页期间来的新输出不会把视图拽回底部，状态栏会显示 `↕ 上翻 N 行` 和 `↓ N 新行 · end 回底`；停在底部时自动跟尾。

鼠标滚轮默认开启：滚轮事件由程序接住，滚的是对话缓冲而不是终端自身的 scrollback（否则往上滚会看到进入 TUI 之前的终端内容）。想交还终端就加 `-no-mouse`。

## 复制

鼠标选中已经由程序自己实现，不依赖终端：

- **按住左键拖动 = 框选**，实时反显；松开左键立刻写入系统剪贴板，结果显示在**状态栏**（`✓ 已复制 N 行 / M 字符`），不占对话区。单击（没有拖动）不复制，避免误触。
- 选区按屏幕单元格计算：中文占两列不会被劈开；软折行（终端宽度导致的换行）复制时拼回同一行，只有真正的段落分界才插入换行。
- 复制通道：先调平台命令（macOS `pbcopy`、Windows `clip`、Linux `wl-copy`/`xclip`/`xsel`），都不存在时退回 OSC 52；后者依赖终端支持（iTerm2 需在 Profiles → Terminal 勾选剪贴板访问）。
- 只在全屏下启用：只有 alt screen 里屏幕行与内容行才一一对应；`-no-mouse` 时整段逻辑关闭，交还终端原生选中（此时按住 shift 拖选也可以）。
- 选区绑定的是当前帧，换会话、重连、滚动都会让它失效——复制只发生在松开左键那一刻。
- 状态栏那条提示只活到下一次按键（或下一次开始框选）：它回答的正是「刚才那下成了没有」。

不用鼠标（或 `-no-mouse`、SSH 里没有鼠标事件）时用键盘选择：`ctrl+y` 进入，`hjkl` / 方向键移动光标，`v` 起选（再按一次取消），`y` 或 `enter` 复制。没有起选时按 `y` 直接复制光标所在整行。`home`/`end` 跳到行首/行尾，`pgup`/`pgdn` 一屏一屏移动并自动跟随滚动；`esc` 退出。

键盘选择同样只支持全屏，坐标用**内容行号**而不是屏幕行号，所以能跨屏选取：光标移出可视区时会自动滚动，选区不会因为翻页而错位。

内联模式或想复制整段时，仍可以按住 shift 用终端原生选中；要长期留存用 `jiaoag events` 导出。

布局是固定的三段，高度由视口算出来，不随输出变化：

```
body   = height - 3 - modal      （内容区：只在这里滚动/裁剪）
modal  = 面板打开时的固定高度      （审批卡片、队列、模型、技能、MCP、? 帮助）
dock   = 3                        （分隔线 + 输入行 + 状态栏）
```

底部三行永远存在：没有会话时输入行显示「等待会话…」，面板打开时显示「面板打开中，esc 返回」。分隔线用 ASCII `-` 铺满，避免东亚宽度不确定的制表符把行撑破。

全屏渲染有一条硬约束：每帧的行数必须恰好等于终端高度。任何一行超出屏幕宽度都会被终端折行，整帧就多出几行，alt screen 因此产生滚动积压，底部状态栏会跟着滚走。所以内容、面板底栏、输入行都要先按显示宽度折行（或截断）再排版；输入行永远单行，超长时横向留尾。

代价：退出后终端 scrollback 里没有这段对话。需要留存用 `jiaoag events` 导出，或加 `-inline` 用内联模式——内联保留 scrollback，但状态栏会被内容推着往下走，`ctrl+f` 仍可随时切回全屏。

## 实现约定

- 颜色只用 8 色基色 + 加粗，不引入 lipgloss：宽度计算（CJK 占两列）本来就要自己写，多一个依赖只剩 API 好看。
- 所有分隔线与面板宽度按视口折行；面板固定 72 列是为了可读性，不与状态栏等宽。
- `?` 面板收纳版本、会话、工作区、附加根与完整键位，这些不进常驻行。

## 斜杠命令补全

输入 `/` 时，输入行上方会列出全部命令（最多 6 行，终端矮时减到 2–4 行）。继续打字按前缀过滤，大小写不敏感；出现空格进入参数区后自动收起。

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 在候选之间移动 |
| `tab` | 把选中的命令名填进输入行（不加尾随空格） |
| `enter` | 输入只是前缀时只补全；打全命令名时执行 |
| `esc` | 只关浮层、保留输入；再按一次才走「取消任务 / 退出」 |

两条刻意的取舍：

- **`enter` 永不执行未打全的命令**。否则输入一个斜杠随手回车，就会触发排在第一位的命令（`/exit` 在最末，但道理一样）。补全只填命令名，参数（如 `/rename` 的标题）继续手打，或改用对应面板。
- **补全只覆盖命令名**，不去异步拉模型名、会话标题。技能是例外：会话建立后拉一次 `skill.list`，把 `disable-model-invocation` 的技能名作为命令候选（行尾标 `技能`）——它们本来就是「只能用户点名」的入口。模型名与会话标题仍走各自面板，在输入行里再实现一遍只会多一套异步状态。

浮层参与底部预算：全屏时浮层多占 N 行，内容区就少 N 行，帧高仍恒等于终端高度（见「实现约定」）。面板（审批 / 队列 / 模型等）打开时不显示，避免两层覆盖物叠在一起。

命令清单只有一份：`internal/tui/complete.go` 的 `commandHints`。`?` 帮助面板与补全共用它，新增命令时不用改两处。

## 内嵌运行时

裸跑 `jiaoag`（没有 `-url`、没有 `-no-spawn`）时，TUI 不再连 `ws://127.0.0.1:8788/ws`，而是在**自己的进程里**直接持有运行时：会话、任务、工具执行、事件流都在同一个进程，不开端口、不需要令牌、不拉起 `jiaoag serve` 子进程。

多个运行时可以同时使用同一个数据目录；调度靠库里的任务占位与租约（ADR-0049）：

| 情况 | 行为 |
|---|---|
| 没有 serve 在监听 | 内嵌运行，不开端口 |
| `jiaoag serve` 在跑 | 探测到端口可达 → 作为 WS 客户端连它（同时它也给 web / 远程用） |
| 另一个内嵌 TUI 在跑 | 照常内嵌：两个运行时共用一个库，靠任务占位与租约避免重复执行 |
| 内嵌 TUI 在跑时再起 `serve` | 照常启动，同样的占位/租约规则 |

`-no-spawn` 现在的含义是「不内嵌、也不拉起，只连已有 serve」，脚本里要固定连某个实例时用它。

## 退出确认

有运行中/等待审批的任务、排队中的任务、或后台进程时，`ctrl+c` 与 `/exit` 第一次只提示：

```
⚠ 还有任务在执行：再按一次 ctrl+c 退出，会取消任务并停止后台进程
```

第二次才真正取消任务、停止后台进程并关闭运行时。没有这些活动时一次就退。

# ADR-0047：TUI 斜杠命令补全

- 状态：已采纳（v2.44）
- 日期：2026-11-26

## 背景

TUI 的斜杠命令已有 11 条（`/models`、`/model`、`/skill`、`/mcp`、`/roots`、`/new`、`/sessions`、`/rename`、`/trust`、`/untrust`、`/exit`），但只能靠 `?` 面板或记忆输入。用户输入 `/` 时没有任何提示，新命令（尤其是 `/trust`、`/untrust`）几乎发现不了。

约束：输入行只支持追加与退格，没有光标移动，所以补全只能做整段替换；底部区高度固定三行，任何新增行都必须进入高度预算，否则全屏帧高会超过终端高度。

## 决策

1. 输入 `/` 即在输入行上方弹出候选浮层，按第一个 token 前缀过滤（大小写不敏感）；出现空格即进入参数区，浮层收起。
2. 只补命令名，不补参数。候选里显示静态用法占位（如 `[标题]`），动态数据（模型、技能、会话）仍走各自面板。
3. `tab` 只补全；`enter` 在输入只是前缀时也只补全，**打全命令名时才执行**。避免 `/` + 回车误触发第一条命令（`/exit`）。
4. `esc` 在浮层打开时只关浮层并保留输入，第二次才走原有的「取消任务 / 退出」；`↑/↓` 移动候选，不占用 `j/k`（它们在此处是普通字符）。
5. 浮层最多 6 行（终端高 ≤20 / ≤14 / ≤8 时分别降到 4 / 3 / 2），作为底部浮层参与 `avail` 预算，保证帧高恒等于终端高度、状态栏仍在最后一行。
6. 命令清单只有一份（`commandHints`），帮助面板与补全都从它生成；测试强制「每条命令都出现在帮助里」。
7. 只做 TUI。Web 端已有按钮行，斜杠命令在网页上属于隐藏功能，需要时另做（`input` 事件 + 绝对定位弹层）。

## 后果

- 新命令只改 `commandHints` 一处，补全与帮助同时生效。
- 打全命令名后浮层立即收起，`enter` 语义不会在「补全」与「执行」之间摇摆。
- 参数仍要手打；`/model` 之类需要名字的命令，用户可能先打命令再被面板接管——两条路径都成立。
- 浮层不改变输入行宽度策略：超长输入仍横向留尾，浮层宽度按终端宽裁剪。

## 备选

- **只做 ghost text**：只能提示一条，用户仍需知道首字母；命令带说明时信息量不足。
- **`enter` 直接执行选中项**：实现最简，但「输入 `/` + 回车」会触发列表第一项，属于危险默认。
- **连参数一起异步补全**：体验最好，但要在输入行里接 `provider.models` / `skill.list` 的回包并处理失效，与已有面板重复。
- **做成全屏面板**：与 `?` 重叠，且在打命令时挡住对话，失去「边看边输入」的意义。

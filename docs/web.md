# Web 前端

TUI 之外的第二个客户端：同一个服务端、同一套 WebSocket 协议，只是把界面换成了浏览器页面。适合「不想开终端」「想用平板看一眼」「想在公司机器上远程批一下审批」这类场景。

## 打开

服务端起来以后，浏览器直接访问同一个监听地址：

```bash
jiaoag serve -config ~/.config/jiaoag/config.yaml   # 默认 127.0.0.1:8787
# 浏览器打开 http://127.0.0.1:8787/
```

页面第一次会要求粘贴令牌（配置里的 `server.token` 或 `server.tokens[].value`）。令牌只存在浏览器 `localStorage`，不会进 cookie、不会进 URL 历史之外的地方；勾掉「记住」就只在本次页面生命周期内有效。

远端使用要先按 [`docs/tls.md`](docs/tls.md) 配好证书，然后访问 `https://<host>:<port>/`——页面自己会把 WS 地址换成 `wss://`。

## 工作区取哪一个

浏览器没有「当前目录」这个概念，所以页面把**服务端进程的启动目录**当作默认工作区：`GET /api/info` 返回 `os.Getwd()`，页面拿它去 `session.manage` 列会话、新开会话也用它。想切到别的项目，就在那个目录启动 `jiaoag serve`；已经记在别的工作区下的会话，可以在「会话」面板里勾「所有工作区」看到，但切换过去后新任务仍按那条会话自己的工作区执行。

## 页面能做什么

和 TUI 基本对齐（除 `!` 本机命令——浏览器里没有 shell）：

| 功能 | 入口 |
|------|------|
| 恢复本目录全部会话为标签 | 打开页面自动（`session.manage` 按工作区列） |
| 新开会话 | 顶栏 `+`（`/new` 的等价物） |
| 切换 / 关闭标签 | 点标签；标签右侧 `×` |
| 提交任务 | 底部输入框，`Enter` 发送、`Shift+Enter` 换行 |
| 取消运行中任务 | 底部「取消」 |
| 审批 diff / 命令 / 外部工具 | 右侧卡片三个按钮；diff 有多个块时可逐块勾选 |
| 会话管理（列表 / 改名 / 删除） | 顶栏「会话」 |
| 会话模型 `/models`、单次模型 `/model` | 顶栏「模型」「单次」 |
| 技能 `/skill`、MCP 状态 `/mcp`、附加根 `/roots`、项目扩展 | 顶栏按钮 |
| 断线重连 | 自动，退避 0.5s → 5s；重连后按 `lastSeq` 增量续传 |

后台会话（没在看的那条标签）依然跑；标签上会出徽标：`!` 待审批、`●` 运行中、`◌` 排队、`·N` 未读。

## 与 TUI 的差异

- **没有 `!本机命令`**。执行命令请让 agent 用 `run_command`（走审批、审计、执行后端）；浏览器里不可能安全地起一个本机 shell。
- **没有全屏/滚动分页那套键盘操作**。页面用浏览器自己的滚动；diff 面板长的时候直接滚动。
- **审批没有 `allow_session` 的快捷键差异**——三个按钮就是三种裁决，和 TUI 的 `y` / `a` / `n` 一一对应。
- 令牌闸门在页面上，只是「别让路过的人随手点」；真正的权限仍是服务端的 Bearer 校验与只读令牌规则（见 [`docs/tokens.md`](docs/tokens.md)）。

## 实现形态（为什么没有构建步骤）

页面是 `internal/webui/assets/` 下的原生 HTML + CSS + ES module，用 `go:embed` 打进二进制。没有 node、没有打包器、没有 `npm install`：`make build` 出来的一个 `bin/jiaoag` 就是全部。

- 路由只有 `/`、`/index.html`、`/app.css`、`/protocol.js`、`/net.js`、`/store.js`、`/ui.js`、`/main.js` 这几个固定文件，其他路径一律 404——静态目录不外泄。
- 静态资源**不需要令牌**（它们不含任何秘密，且浏览器的 `<script>`/`<link>` 也带不了自定义头）；拿数据必须带令牌：`GET /api/info` 与 `/ws` 都会校验。
- `/ws` 的令牌可以走 `Authorization: Bearer`，也可以走 `?token=`——浏览器的 `WebSocket` 构造函数设不了请求头，这是唯一的可行形态。代价是令牌可能出现在代理日志里，所以远端部署建议只走 TLS，并把访问日志的查询串裁掉。
- 协议类型与事件名集中写在 `assets/protocol.js`；`internal/webui/webui_test.go` 会从 `internal/protocol` 与 `internal/domain` 里抽真实常量做比对，服务端改了名字而页面没跟上就会测试失败。

## 边界

- 单个页面就是一个客户端，和 TUI 一样占用一条 WS 连接；多标签是页面内部的多会话视图，不是多条连接。
- 不做用户体系：能拿到令牌的人就是能操作的人。要分权只能靠只读令牌。
- 不持久化对话：刷新页面靠 `event.subscribe(from_seq=0)` 重放重建，和 TUI 的 `-s` 一样。
- 页面不缓存事件，也不同步多个标签页/多个浏览器窗口的输入状态。

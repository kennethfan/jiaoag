5 · 全屏 vs 内联：状态栏“钉底”的两种实现

  • 全屏（alternate screen，vim/htop 那种）：状态栏真正固定在终端最底行，内容区自己滚动（pgup/pgdn、鼠标滚轮）。代价是退出后 scrollback 里没有对话记录，复制长输出要靠内置选择或 jiaoag events。
  • 内联（默认，保留 scrollback）：状态栏钉在当前渲染块的底部——视觉上仍在最下方，但随着内容增长会往下推，终端自身可回滚。

实现上 bubbletea v2 用 View.AltScreen 切换，不需要额外依赖。建议：默认内联，Ctrl+F（或配置 tui.fullscreen: true）切全屏；全屏时状态栏与输入框永远贴底。

7 · 审批按钮的焦点与降级

  • 三个按钮固定顺序：批准一次 / 本会话内都批准 / 拒绝。默认焦点在「批准一次」，按 tab 顺序前移、shift+tab 后退、←→ 同效，enter 执行当前焦点。
  • 快捷键不废：y / a / n 仍然直达对应动作，老习惯不用改；按钮上标出各自字母，一眼能对上。
  • 拒绝键用 err 色：焦点落在「拒绝」时边框与底色切成红色系，避免连按 tab 时手滑确认了拒绝。
  • 无颜色降级：NO_COLOR 或 16 色终端下，焦点用前后的 ▸ … ◂ 包裹 + 反显表示；按钮之间用两个空格分隔，仍然分得清三个槽。
  • 逐块模式：按 v 进入勾选后，底部按钮变成「应用选中块」/「取消」两个，tab 语义不变。
  • esc 不裁决：只收起卡片回到对话视图（状态栏仍显示「等待审批」），避免误触把待办关掉；要拒绝请明确选「拒绝」或按 n。
